# 早间电台原型
已获用户批准：独立网页，iPhone Safari / 主屏幕启动，通过汽车蓝牙听资讯早7点、声动早咖啡。
按北京时间筛选今天发布的全部公开单集，节目顺序固定，同节目按发布时间排序。无更新跳过，读取失败与无更新分开显示。当日进度仅存在本机，跨日清空。一个 HTML audio 元素连续播放，Media Session 支持暂停、继续、跳转、前后集。导航中断不强行恢复；由系统/用户恢复。实机锁屏连播与汽车操作必须由用户验证，不宣称已验证。
后端仅抓取固定两个公开节目页面，提取 NEXT_DATA，校验字段和 HTTPS 音频。不存储或转存音频。不需要账号、数据库、定时任务。页面打开时刷新，未播放时允许刷新。失败提供重试，全部已听完可重新播放。
